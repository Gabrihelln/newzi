# News Engine Mobile

Native React Native CLI + TypeScript project. Use the React Native CLI and Gradle/Xcode workflows; do not add Expo, Expo Go, EAS or expo-* runtime dependencies.

For iOS (Xcode, CocoaPods, Firebase, push, running on an iPhone), follow `../docs/IOS_SETUP.md`.
Light mode must look exactly as it does today; light-only colors go through `colors.tone('#original', colors.token)`.
Run `npm run typecheck` after changing `src/`.
